How it works

C = P - K. Vigenere's rule run in the decryption direction.

C = P - K: Vigenere encryption with the decryption rule.

A worked example

Plaintext:

MEET ME BY THE OLD CLOCK TOWER AT DAWN

Key: LEMON

Ciphertext:

BASF ZT XM FUT KZP PAKQW GDSSD NI ZOIA

This example is generated by running the cipher when the page is built, and the round trip is checked, so it always matches what the solver does.

How it is broken

The same two-stage attack. A message solved under this name also solves under Vigenere with the complementary key, which is why the solver reports the better-known name on a tie.

History and context

The German army's variant, and a good illustration that a cipher's identity is the algebra, not the label.
