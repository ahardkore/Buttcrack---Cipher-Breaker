# Kryptos education paths

Each path uses the same evidence vocabulary and ends with an exact verification task.

| Path | Tiny example | Interactive tool | Worksheet | Historical case |
|---|---|---|---|---|
| Beginner | Caesar shift of `ABC` | Symbol Guide Caesar demo | Symbol inventory | al-Kindi and frequency analysis |
| Puzzle enthusiast | `MEETATNOON` transposition | Transposition Lab | Grid worksheet | Kasiski and the Vigenere story |
| Historical reader | Keyed alphabet | Symbol Guide | Source-note worksheet | CIA sculpture and public secrecy |
| Classroom | crib `THE` over a toy stream | Crib Lab | Printable crib sheet | Rejewski, Turing, and team cryptanalysis |
| Working cryptanalyst | exact round trip | Verification Center | Research session JSON | Reproducible negative evidence |

## Completion standard

Every path ends with a result that is either explicitly verified or explicitly
marked as a hypothesis. No educational activity uses a language score alone as
its answer key.
